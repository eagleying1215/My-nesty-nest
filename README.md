# Ozon 秋冬袜子工作台

个人使用的中文选品与上架准备工具。只需 Python 3.10+，无需安装第三方依赖、注册账号、购买服务或提供 API 密钥。

## 安装与启动

在 GitHub 仓库页面点击绿色 **Code → Download ZIP**，下载后先解压，不能在压缩包内运行。

Windows 新手推荐：从 python.org 安装 Python 3.10+，安装时勾选 **Add python.exe to PATH**，然后双击解压文件夹里的 **启动工作台-Windows.bat**，会自动打开浏览器。使用期间保留终端窗口。

macOS：安装 Python 3.10+ 后，可在项目文件夹的终端运行 `python3 启动工作台.py`。Linux 同样适用。无需安装额外的 Python 软件包。

也可在项目文件夹打开终端：

```bash
python3 app.py
```

Windows 可使用 `python app.py`。在自己电脑的浏览器打开 `http://127.0.0.1:8000`。停止时在终端按 Ctrl+C。重启执行同一命令，数据仍然保留。云端运行时，浏览器须通过运行平台提供的端口访问能力连接该进程；线上访问请按 deploy/README.md 配置 HTTPS、密码和持久化磁盘。

默认监听本机 127.0.0.1:8000。可通过 `PORT` 修改端口、`WORKBENCH_DATA_DIR` 修改数据目录；`HOST` 仅在清楚网络访问风险时配置。本机使用默认无需密码；线上模式强制配置密码摘要。

## 无法打开时先看这里

`127.0.0.1` 和 `localhost` 都表示当前使用浏览器的电脑。只在云机器启动程序，不能从自己电脑直接访问这个地址。当前聊天环境没有提供可用的网站预览或端口转发工具，因此没有已验证的云端访问网址。

推荐在自己电脑使用：安装 Python 3.10+，将整个项目文件夹下载到电脑，在该文件夹运行 `python 启动工作台.py`（macOS/Linux 用 `python3 启动工作台.py`）。它会启动本机服务并自动打开浏览器。使用时保留终端窗口，关闭终端会停止网站。Windows 也可在 Python 文件关联正常时双击“启动工作台.py”。

- “连接被拒绝”：确认终端程序仍在运行，查看启动错误，重新启动。
- “端口已被占用”：确认是否已经启动过工作台；不要同时启动两份。需要换端口时使用 `PORT` 环境变量。
- 云机器暂停或重启后：数据仍在，但服务进程需要重新启动。保存环境配置不会让服务永久在线。
- 如需云端访问，必须由运行平台提供端口转发入口或另行部署；不要把本机地址当作云端网址。

## 怎么使用

1. 点击“新增商品”，录入资料并保存。未知数据留空，界面显示“待补充”。没有预置商品或隐藏演示数据。
2. 在“供应商核验”记录代发能力、库存日期、出库与售后约定、样品结果。默认未核实，须自行确认。
3. 在“利润核算”填写全部关键成本、汇率与费率，点击计算。实际零费用请显式填写 0，缺失时不会假定免费。
4. 在“图片与俄语文案”上传本地实拍、记录六张图片制作状态，复制制作指令到你选择的 AI 工具，人工审核后粘贴俄语文案。点击保存保留图片与文案。
5. 在“上架检查”逐项核实当前平台规则，记录依据与日期，自行更新进度。
6. 每次编辑、上传后点击“保存修改”。切换商品或关闭页面前会提示未保存内容。切换页签保留当前编辑。

## 核算口径

- 采购价为人民币/双；每单销售数量为双数，必须是正整数。
- 代发、包装、国内运费、跨境物流按人民币/整单填写，不能再包含已录入的采购价。
- 汇率方向：**1 人民币 = X 卢布**。
- 平台费率、广告预算比例、售后损耗比例均以整单卢布售价为基数，分别扣一次。不内置 Ozon 费率。
- 平台固定费为卢布/单。若实际平台计费基数与此不同，先换算有效比例再输入并在备注说明；不适用此模型时不要据此定价。
- 人民币成本 C = 采购价 × 双数 + 各项人民币整单成本。
- 利润（卢布）= 售价 × (1 − 平台比例 − 广告比例 − 售后比例) − C × 汇率 − 固定费用。
- 利润率 = 利润 / 售价；盈亏平衡售价 = (C × 汇率 + 固定费) / (1 − 各项比例之和)。零售价时利润率无定义。
- 比较单双与多双方案时分别输入整单售价、物流、代发、包装和国内运费；共用采购单价、汇率和平台费用规则。比较结果仅临时计算，不会覆盖商品。
- 这是估算工具，未自动包含税费、汇兑差价或其他未录入成本。请将相关成本合理归入费用并备注；比例之和须小于 100%。

## 保存、备份与恢复

数据和图片保存在项目 `data/workbench.sqlite3`，不是浏览器缓存。刷新、更换同机浏览器、重启进程均保留；不要删除 data 文件夹。

- **完整备份**：顶部点击“完整备份”，下载包含所有商品、图片、核验、清单、进度与文案的 JSON，保管到私密位置。
- **恢复**：先备份当前数据，点击“恢复备份”选择上述 JSON，确认后替换全部商品。无效备份会拒绝并保留现有数据库。
- 每张图片最大 2MB，每款最多30张；单次备份恢复上限40MB。大库请停服后备份/恢复整个 data 文件夹（保留原副本），不要在数据库写入时直接复制单个 SQLite 文件。
- CSV 是**内部商品资料**，未知字段导出为“待补充”，含演示标记并防护公式注入。没有匹配当前 Ozon 类目模板，不能直接上传 Ozon。
- 单款“资料包”导出 JSON，含实拍 data URL、完整字段、核验、文案、任务状态及估算，可交给后续制作流程使用，不是平台提交文件。
- data/ 已列入 Git 忽略。下载的备份应存放仓库外，不要将私人数据、密钥或密码提交到 Git。

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试使用临时数据库，覆盖商品新增/编辑/删除/查询、服务重启持久化、包含图片的备份恢复、无效恢复原子性、缺失费用、利润公式、CSV 和上架资料包。

## 第一版边界

未连接 Ozon、供应商、翻译或图片生成服务；不验证实时库存、平台规则和当前费率，不自动抓取、下单、发布或改价。图片提示词及俄语生成指令是可复制的任务说明，不是生成结果。“通过”仅代表你手工记录的判断。
